# Portugal National Team Player Analysis

This project uses FIFA 23 and FIFA 24 player ratings to explore which player attributes matter for squad selection and how those attributes can inform lineup decisions.

**[Open the analysis notebook](Portugal_Player_Analysis_and_Real_Time_Strategy.ipynb)**

## Analysis

- Cleaned and normalised player data for exploratory analysis and modelling.
- Compared attributes such as ball control, acceleration, passing and free-kick accuracy, with attention to each player's position.
- Used visualisations and statistical analysis to identify player strengths and explore lineup options.
- Explored logistic regression, random forest, support vector machines and a convolutional neural network for lineup prediction.

## Scope

FIFA ratings are the inputs for this analysis. Treat the lineup suggestions as exploratory and interpret the model results within the dataset and evaluation used in the notebook.
